# yakureki-template-app

薬歴入力用の定型文言をワンクリックで組み立てるための配布用Webアプリです。
以前のGoogle Apps Script + スプレッドシート版と違い、**サーバーやスプレッドシートを使わず**、
データはすべて利用者本人の端末（ブラウザの `localStorage`）に保存されます。
GitHub Pages で公開して、URLを配るだけで誰でも使い始められます。

## この版の特徴

- サーバー・データベース不要。GitHub Pagesの静的ホスティングだけで動作します。
- 各利用者のデータ（登録した文言・お気に入りリンク）は、その人の端末のブラウザにのみ保存されます。
  他の端末やブラウザを開いても、別データとして扱われます（＝利用者ごとに独立）。
- 「設定・管理」画面から、いつでも
  - JSONファイルへのバックアップ（書き出し）
  - JSONファイルからの復元（読み込み）
  - 初期状態へのリセット
  ができます。機種変更やブラウザの初期化に備えて、定期的なバックアップを利用者に案内してください。

## ファイル構成

```
yakureki-template-app/
└── index.html   ← アプリ本体（このファイル1つだけで動作します）
```

外部ライブラリ（Bootstrap / Bootstrap Icons）はCDNから読み込んでいるため、
`index.html` 単体をアップロードするだけで完結します。

## 初期データ（標準テンプレート）について

初めてこのアプリを開いた利用者にもすぐに使い方が伝わるよう、
「服薬状況」「副作用・体調」「生活状況」「説明・指導」「検査値」「次回・その他」の
6区分・約25件の、薬局でよく使われる薬歴文言をあらかじめ組み込んでいます
（`index.html` 内の `getDefaultMasterData()` 関数）。

- 「説明・指導」区分の一部の項目には、あえてタグ（F列）を設定し、
  複数選択したときに読点（、）で自動的につながる機能のデモを兼ねています
  （例：「血糖値について」＋「血圧値について」＋「の説明をした。」を選択すると
  「血糖値について、血圧値についての説明をした。」と組み立てられます）。
- あくまで一般的な定型文の**ひな形**です。実際の患者名・具体的な数値など
  個別の患者情報は、この文言データ自体には含めない運用にしてください
  （詳しくは下記「セキュリティについて」参照）。
- 中身は「設定・管理」画面からいつでも自由に編集・追加・削除できます。
  自施設の運用に合わせて内容を入れ替えた後、「JSONファイルにバックアップ」しておくと、
  他の端末にもそのまま配布できます。

### 初期状態2（薬効説明テンプレート）

「設定・管理」画面の「テンプレートの読み込み」から、上記の標準テンプレート（初期状態1）とは別に、
実際の薬局運用をベースにした「初期状態2」も読み込めるようにしています。

- 「鎮咳」「去痰」「アレルギー」「解熱鎮痛」「気管支」「コロフル（コロナ・インフル）」「抗生剤」など、
  薬効ごとの区分と、薬品名＋服薬指導文言のセット（全54件）を収録しています。
- F/G/H列のタグ機能（小文字タグの薬品を選ぶと、対応する大文字タグの説明文が自動でチェックされ、
  改行なしで薬品名の直後に続く）を実際に使った構成になっているため、タグ機能の実例としても参考になります。
- お気に入りリンク（「画像説明」「白鷺病院」）もあわせて読み込まれます。
- 読み込むと現在の「項目」「お気に入りリンク」のデータは置き換わります。
  必要に応じて先に「JSONファイルにバックアップ」を行ってください。

初めてアクセスした利用者にはまず初期状態1（一般的なひな形）が表示され、
「設定・管理」から初期状態2（実例ベースの詳細テンプレート）に切り替えられる、という構成です。

## セキュリティについて（不特定多数への配布を前提とした注意点）

このアプリを「誰でもアクセスできるURL」として配布すること自体は、以下の理由から
一般的なセキュリティ上の問題は小さいと考えられます。

- **サーバーにデータを送信しない構成**です。入力・選択した内容はすべて
  利用者本人のブラウザ内（`localStorage`）だけで完結し、外部（Anthropic、GitHub、
  開発者を含む第三者）に送信されることはありません。
- **利用者ごとにデータが分離**されます。`localStorage` はブラウザ・端末・オリジン
  （このアプリのURL）単位で独立しているため、Aさんの端末での編集内容がBさんに
  見える、ということは起こりません。
- GitHub Pagesは自動的に **HTTPS** で配信されるため、通信経路上の盗聴リスクも
  一般的な静的サイトと同程度に抑えられます。

一方で、次の点はご留意ください（アプリ固有というより、Webアプリ全般・
`localStorage` 全般の一般的な性質です）。

1. **公開リポジトリの中身は誰でも閲覧できます。** リポジトリをPublicにする場合、
   `index.html` のソースコードは誰でも見られます。実際の患者名・個人情報などを
   **コード自体に書き込んでコミットしない**でください（テンプレート文言の
   ひな形のみを想定しています）。
2. **`localStorage` は暗号化されていません。** 端末を紛失した場合や、
   共有端末（受付共用PCなど）で他の人があとから同じブラウザを開いた場合、
   保存されている文言データを閲覧される可能性があります。個人が特定できる
   情報（患者氏名・生年月日など）はこの文言データには入力せず、
   「定型文の組み立てにのみ使う」運用を徹底することをおすすめします。
3. **バックアップJSONファイルの取り扱いにも同様の注意が必要です。** 書き出した
   JSONファイルにも患者情報を含めないでください。含めない前提であれば、
   メールやUSB等での受け渡しも通常のテキストファイルと同程度のリスクです。
4. **利用者を限定したい場合**、GitHub Pages自体にはログイン機能がないため、
   URLを知っていれば誰でもアプリ（＝空のテンプレートツール）自体は開けます。
   施設内限定で配りたい場合は、リポジトリをPrivateにした上でGitHub Enterprise等の
   アクセス制限付きPages、または社内のイントラサーバーでの配信をご検討ください。

まとめると、「**このツールに実際の患者情報を保存・入力しない**」という運用ルールさえ
守っていただければ、不特定多数に配布しても情報漏えいのリスクは小さい構成です。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成します。
   - リポジトリ名: `yakureki-template-app`
   - Public / Private どちらでも可（社内配布などで限定したい場合はPrivateでもPages機能自体は有料プランが必要な場合があります）
2. このリポジトリのルートに `index.html` をそのままアップロード（コミット）します。
   - サブフォルダに入れず、リポジトリ直下に置いてください。
3. GitHubの `Settings` タブ → 左メニューの `Pages` を開きます。
4. 「Build and deployment」の `Source` を `Deploy from a branch` に設定します。
5. `Branch` を公開したいブランチ（通常は `main`）、フォルダを `/(root)` にして `Save` します。
6. 数十秒〜数分待つと、以下のようなURLでアプリが公開されます。

```
https://<あなたのGitHubユーザー名>.github.io/yakureki-template-app/
```

7. このURLを利用者に配布すれば、そのままブラウザで使い始められます。

### 更新のしかた

`index.html` の内容を修正して同じ場所に上書きコミットするだけで、
数分後には公開ページにも反映されます。

## 利用者から見た使い方

1. 上記URLを開くと、初回はサンプルの文言が表示されます。
2. 「入力モード」で文言をタップ/クリックすると、右上（またはコンパクト表示）に
   組み立てられた文章が表示され、自動的にクリップボードへコピーされます。
3. 「設定・管理」から、自分の薬局でよく使う文言・区分・タグ・お気に入りリンクを
   自由に編集・追加・削除できます。編集内容は「この内容をこの端末に保存する」を押すと
   その端末に保存されます。
4. データは端末ごとに独立して保存されるため、複数の端末（PC・タブレットなど）で
   同じ内容を使いたい場合は、1台でバックアップ（JSON書き出し）してから、
   他の端末で「JSONファイルから復元」を行ってください。

## データ形式（バックアップJSON）

「JSONファイルにバックアップ」で書き出されるファイルは、次のような構造です。
このファイルを使って別端末への引き継ぎや、他の担当者への配布用テンプレートの共有ができます。

```json
{
  "app": "yakureki-template-app",
  "version": 1,
  "exportedAt": "2026-09-27T12:00:00.000Z",
  "masterData": [
    {
      "category": "区分名",
      "text": "表示・出力される文言",
      "fgh": ["", "", ""],
      "noLineBreak": false
    }
  ],
  "linkData": [
    { "name": "リンクの表示名", "url": "https://example.com" }
  ]
}
```

- `fgh`: F/G/H列に相当するタグ。小文字で同じタグを複数の項目に付けると、
  選択時に読点（、）でつながって出力されます。大文字のみのタグはコンパクト表示から除外されます。
- `noLineBreak`: `true` にすると、直前の項目との間で改行せずに続けて出力します。

配布時に「業界標準のテンプレート」を最初から入れておきたい場合は、
このJSON形式でサンプルファイルを作成し、利用者に最初の「復元」として
読み込んでもらう、という配り方も可能です。

## 旧バージョン（GAS + スプレッドシート版）との違い

| 項目 | 旧版（GAS） | 今回の配布版 |
|---|---|---|
| ホスティング | Google Apps Script Webアプリ | GitHub Pages（静的） |
| データ保存先 | スプレッドシート（共有） | 各端末の `localStorage`（個別） |
| 複数人での共有 | 自動的に全員で共有 | されない（JSONで手動共有） |
| バックアップ | スプレッドシートの版履歴 | JSONファイルの書き出し／読み込み |
| サーバー費用・管理 | Googleアカウント依存 | 不要 |

複数人・複数端末で常に同じデータを共有したい運用が必要な場合は、
今回の「端末ローカル保存」ではなく、Firebase等の外部データベースを使う構成が
別途必要になりますので、その際はお知らせください。
